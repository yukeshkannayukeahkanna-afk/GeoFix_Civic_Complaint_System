🚀 GeoFix Setup

Your app is ready! Just need to start a local server...

⚠️ Important: To test PWA features (app installation), you need to run a local web server. Just opening the HTML file won't work for PWA installation.

🎯 Quick Start - Choose One Method:

✅ Option 1: Install Python (Easiest)

  1. Download Python: Download Python
  2. Important: Check "Add Python to PATH" during installation!
  3. After install, open PowerShell in this folder and run:
python -m http.server 8080

Or simply double-click: start-app.bat

Then open: http://localhost:8080

✅ Option 2: Install Node.js

  1. Download Node.js: Download Node.js
  2. After install, open PowerShell and run:
npx http-server -p 8080 -o

Or simply double-click: start-app.bat

✅ Option 3: Use VS Code Live Server (If you have VS Code)

  1. Open this folder in VS Code
  2. Install "Live Server" extension
  3. Right-click on index.html
  4. Click "Open with Live Server"

✅ Option 4: Use PHP (If installed)

php -S localhost:8080

📱 After Server Starts:

  1. Your browser will open to http://localhost:8080
  2. Look for the "Install App" button at the bottom right
  3. Click it to install GeoFix as a mobile app!
  4. Find the app icon on your home screen/desktop

🔧 Troubleshooting:

  • Can't install Python/Node? Try Option 3 (VS Code) or ask your IT admin
  • Port 8080 is busy? Use a different port: python -m http.server 3000
  • Still stuck? Check the full guide in APP_INSTALLATION_GUIDE.md
