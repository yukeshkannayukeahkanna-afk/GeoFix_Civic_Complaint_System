# 📱 GeoFix App Installation Guide

Welcome to GeoFix! This guide will help you install the GeoFix Progressive Web App (PWA) on your device for the best mobile app experience.

## 🌟 Why Install the App?

Installing GeoFix as an app gives you:
- ✅ **Full-screen experience** - No browser UI clutter
- ✅ **Home screen icon** - Quick access like a native app
- ✅ **Offline access** - Use core features even without internet
- ✅ **Push notifications** - Get updates on your complaints (coming soon)
- ✅ **Faster loading** - Cached resources for instant startup
- ✅ **App-like feel** - Smooth animations and transitions

---

## 📲 Installation Instructions

### For Android (Chrome, Edge, Samsung Internet)

#### Method 1: Install Button (Easiest)
1. Open GeoFix in your mobile browser
2. Look for the **"Install App"** button at the bottom right of the screen
3. Tap the button and follow the prompts
4. The app will be added to your home screen!

#### Method 2: Browser Menu
1. Open GeoFix in Chrome/Edge
2. Tap the **menu icon** (three dots) in the top right
3. Select **"Add to Home Screen"** or **"Install App"**
4. Give it a name (e.g., "GeoFix") and tap **Add**
5. The app icon will appear on your home screen

#### Method 3: Browser Banner
- Some browsers automatically show an "Add to Home Screen" banner when you visit GeoFix
- Simply tap **"Add"** when prompted

**After Installation:**
- Find the GeoFix icon on your home screen
- Tap to open - it will launch in full-screen mode!
- You can now use it just like a native app

---

### For iPhone/iPad (Safari)

**Note:** iOS requires using Safari browser for PWA installation.

1. Open GeoFix in **Safari** (not Chrome or other browsers)
2. Look for the **iOS install banner** at the bottom of the screen with installation instructions
3. Tap the **Share button** (square with arrow pointing up) at the bottom of Safari
4. Scroll down and tap **"Add to Home Screen"** 
5. Edit the name if desired and tap **"Add"** in the top right
6. The GeoFix icon will appear on your home screen!

**Opening the App:**
- Find the GeoFix icon on your home screen
- Tap to launch - it opens in full-screen mode
- The app runs independently from Safari

**iOS Tips:**
- Make sure you're using Safari, not Chrome or other browsers
- If you don't see "Add to Home Screen", try updating iOS
- The app works on iPhone, iPad, and iPod Touch

---

### For Desktop (Windows/Mac/Linux)

#### Chrome/Edge on Desktop

1. Open GeoFix in Chrome or Edge
2. Look for the **"Install App"** button in the bottom right
   - OR look for the **install icon** (⊕ or 🖥️) in the address bar
3. Click the button/icon
4. Click **"Install"** in the popup dialog
5. GeoFix will open in its own window!

**After Installation:**
- The app appears in your Start Menu/Applications
- Pin it to taskbar for quick access
- Opens in a standalone window (no browser tabs)
- Can be launched like any other desktop app

#### Firefox on Desktop

1. Firefox doesn't support PWA installation by default
2. **Alternative:** Bookmark the site for quick access
3. Or use Chrome/Edge for full app experience

---

### For Microsoft Edge (All Platforms)

1. Open GeoFix in Edge
2. Click the **"App available"** icon in the address bar
   - Or click the Settings menu (•••) → Apps → Install GeoFix
3. Click **"Install"** in the dialog
4. The app will install and launch!

## 🛠️ Troubleshooting

### "Install App" button not showing?

**Possible reasons:**
1. **Already installed** - Check your home screen/apps
2. **Not using HTTPS** - PWAs require secure connection
3. **Browser not supported** - Use Chrome, Edge, or Safari
4. **Cache issue** - Clear browser cache and reload

### App won't install on iOS?

1. Make sure you're using **Safari** (not Chrome)
2. Update to latest iOS version
3. Check you have enough storage space
4. Try closing Safari completely and reopening

### Desktop install not working?

1. Update your browser to the latest version
2. Make sure cookies and JavaScript are enabled
3. Check browser settings allow PWA installation
4. Try a different browser (Chrome or Edge recommended)

### App crashes or won't open?

1. **Clear app data:**
   - Android: Long-press app icon → App Info → Storage → Clear Data
   - iOS: Delete app and reinstall
   - Desktop: Uninstall and reinstall

2. **Check internet connection** for first launch
3. **Update your device/browser** to latest version
